# titulo

> El proyecto consiste en una ventana donde podemos crear 4 distintas figuras, las cuales son línea, circulo, rectángulo y triangulo, donde dichas figuras se le puede cambiar el tamaño, pintarlas y rotarlas.

## Construido con
- C++
- OpenGL 3.3
- GLFW
- GLAD
- Dear ImGui

## Demostración e explicación del código
[Video]( https://github.com/Katherin-Tabares/Proyecto-Paint)

## Empezando
Para tener una copia del proyecto, sigue estos pasos.
### Requisitos previos
--Windows
--Visual Studio
--OpenGL 3.3
--GLAD
--GLFW
-Dear ImGui

### Instalar
1. Clonar el repositorio
git clone https://github.com/Katherin-Tabares/Proyecto-Paint.git
2. Abrir el proyecto en Visual Studio.
3. Verificar que las librerías GLAD, GLFW, Dear ImGui estén correctamente configuradas.
4.Compilar el proyecto en Visual Studio.
##Uso
1.	Ejecutar el programa desde Visual Studio.
2.	Seleccionar una de las figuras del panel de ImGui.
-- Línea.
-- Circulo.
-- Rectángulo.
-- Triangulo.
3. Con el mouse hacer clic sobre la grilla donde mediante los puntos se establece la figura.
--Lines: Un clic para establecer el inicio de la línea, y un segundo clic para el final de la línea.
-- Circulo: Un clic para establecer el centro del círculo, y un segundo clic para el radio del círculo.
-- Rectángulo: Un clic para establecer la esquina superior Izquierda del rectángulo, y un segundo clic para establecer la esquina inferior derecha del rectángulo.
--Triangulo: Un clic para establecer un punto del triángulo, y así mismo dos establecemos dos puntos más para generar el triángulo.
4. Con las ventanas desplegables de las figuras, logramos modificar los colores, el tamaño, y la rotación
5. Con el botón Eliminar Figura, para eliminar la figura de la grilla.
##Características
--Ventana de 1080 x 1080 pixeles, con una dimensión de la grilla de 250x250 pixeles
--Creación de figuras como la línea, círculos, rectángulo y triangulo.
--Selecciona de colores.
--Modifica el tamaño.
--Rotación de las figuras.
--Elimina las figuras individuales.
--Lista de figuras creadas.
